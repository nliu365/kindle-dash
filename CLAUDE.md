## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on nliu365/kindle-dash, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, both created only when they're first needed. See `docs/agents/domain.md`.
